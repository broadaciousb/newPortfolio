## Getting Started

1. Clone Repository

git clone https://github.com/broadaciousb/summaristProject.git

2. Install Dependencies

npm install

3. Run Development Server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
